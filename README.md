# ألعاب الشلة 🎲

ألعاب جماعية تنلعب من الجوال: المضيف يفتح غرفة على شاشة (لابتوب أو تلفزيون)، والكل يمسح الباركود ويدخل ويجاوب من جواله.

## اللعبة الأولى: «وش في بالك؟» 🤔

- يطلع سؤال للكل، مثل: «اذكر لون من ألوان قوس قزح».
- كل لاعب يكتب الجواب اللي يتوقع أغلب الشلة بيكتبونه.
- قبل ما يرسل، يختار رقم من **1 إلى 15** يراهن فيه. كل رقم يستخدمه **مرة وحدة بس** في اللعبة، والرقم ينحرق سواء فاز أو خسر.
- **أكبر مجموعة** جاوبت نفس الجواب تفوز، وكل واحد فيها ياخذ نقاط الرقم اللي راهن فيه. لو تعادلت أكبر مجموعتين أو أكثر، الكل يفوز.
- الجواب اللي ما قاله إلا شخص واحد ما يفوز أبداً.
- الأجوبة المتشابهة تنجمع تلقائياً (`أحمر` = `الأحمر` = `احمر`)، والمضيف يقدر يدمج المرادفات بيده قبل ما يعتمد النتيجة (مثلاً `بحر` و`شاطئ`).

### شاشة المضيف
- باركود ورقم غرفة من 4 أرقام، وقائمة اللاعبين (ويقدر يطرد أحد).
- الإعدادات: عدد الأسئلة (3–15)، المؤقت، ومصدر الأسئلة (بنك جاهز فيه 160 سؤال، أو أسئلة يكتبها المضيف، أو الاثنين).
- يشوف مين جاوب بدون ما يشوف الأجوبة، وبعدها يكشف ويدمج ويعتمد النتيجة.
- لو المضيف يبي يلعب معهم، يمسح الباركود بجواله مثل الباقين.

## التشغيل على جهازك (نفس الواي فاي)

تحتاج [Node.js](https://nodejs.org) نسخة 18 أو أحدث.

```bash
npm install
npm start
```

افتح `http://localhost:3000` على اللابتوب واضغط «أنشئ غرفة». الباركود يطلع تلقائياً بعنوان جهازك على الشبكة (مثل `http://192.168.1.5:3000`) عشان الجوالات اللي على نفس الواي فاي تقدر تدخل.

> لو الجوالات ما قدرت تفتح الرابط، تأكد إنهم على نفس الشبكة وإن جدار الحماية (Firewall) في جهازك يسمح بالمنفذ 3000.

## النشر مجاناً على الإنترنت (Render)

عشان تلعبون من أي مكان بدون واي فاي مشترك:

1. ادخل [render.com](https://render.com) وسجّل بحساب GitHub.
2. اختر **New → Blueprint** واختر هذا المستودع. ملف `render.yaml` فيه كل الإعدادات.
3. بعد ما يخلص، افتح الرابط اللي يعطيك إياه وأنشئ غرفة.

> النسخة المجانية في Render تنام لو ما أحد استخدمها فترة، فأول فتحة ممكن تاخذ دقيقة تقريباً.

لو حاب تحدد عنوان الباركود بنفسك، حط متغير البيئة `PUBLIC_URL` (مثلاً `https://games.example.com`).

## للمطورين

```bash
npm test   # اختبارات المنطق: توحيد الكتابة، التجميع، الفوز، المراهنة، الغرف
```

| الملف | وش فيه |
| --- | --- |
| `server.js` | سيرفر Express + Socket.io، رابط الانضمام والباركود |
| `src/rooms.js` | الغرف واللاعبين والرجوع بعد الانقطاع، وتجهيز البيانات لكل شاشة |
| `src/games/herd.js` | منطق لعبة «وش في بالك؟» |
| `src/normalize.js` | توحيد الكتابة العربية لمقارنة الأجوبة |
| `data/questions.json` | بنك الأسئلة |
| `public/` | صفحات المضيف واللاعب (HTML/CSS/JS بدون build) |

السيرفر هو المرجع لكل شي، ويرسل لكل جهاز صورة كاملة عن حالة اللعبة حسب دوره: اللاعب ما يشوف أجوبة غيره قبل ما تنعتمد النتيجة. البيانات محفوظة في الذاكرة بس، والغرف تنحذف بعد 6 ساعات بدون نشاط.
