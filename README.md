# ألعاب الشلة 🎲

ألعاب جماعية تنلعب من الجوال: المضيف يفتح غرفة على شاشة (لابتوب أو تلفزيون)، والكل يمسح الباركود ويدخل ويجاوب من جواله.

**العب الحين:** https://herd-game-hf2y.onrender.com

## اللعبة الأولى: «عقلية القطيع» 🐄

مستوحاة من لعبة الحفلات المشهورة **Herd Mentality**.

- يطلع سؤال للكل، مثل «اذكر لون من ألوان قوس قزح» أو «شاي ولا قهوة؟».
- قبل ما يرسل جوابه، كل لاعب يختار رقم من **1 إلى 15** يراهن فيه. كل رقم يستخدمه **مرة وحدة بس** في اللعبة، والرقم ينحرق سواء فاز أو خسر.
- الفايز ياخذ نقاط الرقم اللي راهن فيه، والخسران يروح عليه رقمه.
- اللي ما يجاوب على السؤال قبل الكشف ينحرق **أقل رقم باقي عنده**.

### الأطوار
| الطور | الهدف | مين يفوز |
| --- | --- | --- |
| 🐄 **مع القطيع** | جاوب نفس جواب الأغلبية | أكبر مجموعة جاوبت نفس الجواب. لو تعادلت أكبر مجموعتين أو أكثر، الكل يفوز. والجواب اللي ما قاله إلا شخص واحد ما يفوز. |
| 🦄 **عكس القطيع** | جاوب جواب صحيح ما أحد غيرك يقوله | كل واحد جوابه ما تكرر. لو اثنين أو أكثر قالوا نفس الجواب، يخسرون كلهم. |

طور «عكس القطيع» له بنك أسئلة خاص (60 سؤال) أجوبتها محدودة، مثل «يوم من أيام الأسبوع» أو «كوكب في المجموعة الشمسية»، عشان الانفراد بالجواب يحتاج تفكير.

### مراجعة الأجوبة
- الأجوبة المتشابهة تنجمع تلقائياً (`أحمر` = `الأحمر` = `احمر`).
- المضيف يقدر **يدمج** جوابين بنفس المعنى (مثلاً `بحر` و`شاطئ`).
- ويقدر **يرفض** أي جواب غلط فما يفوز صاحبه. هذا مهم في «عكس القطيع» عشان ما أحد يكتب أي كلام عشان ينفرد.
- كل دمج أو رفض يقدر يتراجع عنه قبل ما يعتمد النتيجة.

### شاشة المضيف
- باركود ورقم غرفة من 4 أرقام، وقائمة اللاعبين (ويقدر يطرد أحد).
- الإعدادات: طور اللعبة، عدد الأسئلة (3–15)، المؤقت، ومصدر الأسئلة (بنك جاهز لكل طور، أو أسئلة يكتبها المضيف، أو الاثنين).
- يشوف مين جاوب بدون ما يشوف الأجوبة، وبعدها يكشف ويدمج ويرفض ويعتمد النتيجة.
- لو المضيف يبي يلعب معهم، يمسح الباركود بجواله مثل الباقين.

## النشر على الإنترنت (Render) — مجاناً

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/HadiTAG7/Games)

1. اضغط الزر اللي فوق (أو ادخل [render.com](https://render.com) واختر **New → Blueprint**).
2. سجّل دخول بحساب GitHub واسمح لـ Render يشوف مستودع `Games`.
3. Render يقرأ ملف `render.yaml` ويجهّز كل شي لحاله (خطة مجانية، سيرفر فرانكفورت لأنه الأقرب للسعودية). اضغط **Apply / Deploy**.
4. بعد دقيقتين تقريباً يعطيك رابط مثل `https://herd-game.onrender.com`. افتحه واضغط «أنشئ غرفة»، والباركود يطلع تلقائياً بهذا الرابط.

أي تحديث ينرفع على GitHub، Render ينشره تلقائياً.

> **ملاحظات النسخة المجانية:**
> - لو ما أحد استخدم الموقع 15 دقيقة ينام، وأول فتحة بعدها تاخذ حوالي دقيقة. افتح الرابط قبل ما تجتمعون بشوي.
> - وأنتم تلعبون ما ينام، لأن الجوالات متصلة طول الوقت.
> - الغرف محفوظة في الذاكرة، فلو السيرفر نام أو انعاد نشره تنمسح الغرف، وتنشئون غرفة جديدة.

### ليش مو Vercel؟
اللعبة تحتاج سيرفر واحد يبقى شغّال ومتصل بكل الجوالات (WebSocket) ويحفظ حالة الغرفة في ذاكرته. Vercel يشغّل الكود كدوال مؤقتة (Serverless) ممكن تنقسم على أكثر من نسخة وتنقفل بعد مدة، فالمضيف واللاعبين ممكن يوصلون لنسخ مختلفة وما يشوفون نفس الغرفة. عشان كذا Render (أو أي استضافة تشغّل سيرفر Node عادي) هو الخيار الأنسب.

## التشغيل على جهازك (نفس الواي فاي)

تحتاج [Node.js](https://nodejs.org) نسخة 18 أو أحدث.

```bash
npm install
npm start
```

افتح `http://localhost:3000` على اللابتوب واضغط «أنشئ غرفة». الباركود يطلع تلقائياً بعنوان جهازك على الشبكة (مثل `http://192.168.1.5:3000`) عشان الجوالات اللي على نفس الواي فاي تقدر تدخل.

> لو الجوالات ما قدرت تفتح الرابط، تأكد إنهم على نفس الشبكة وإن جدار الحماية (Firewall) في جهازك يسمح بالمنفذ 3000.

لو حاب تحدد عنوان الباركود بنفسك، حط متغير البيئة `PUBLIC_URL` (مثلاً `https://games.example.com`).

## للمطورين

```bash
npm test   # اختبارات المنطق: توحيد الكتابة، التجميع، الفوز في الطورين، المراهنة، الرفض، الغرف
```

| الملف | وش فيه |
| --- | --- |
| `server.js` | سيرفر Express + Socket.io، رابط الانضمام والباركود |
| `src/rooms.js` | الغرف واللاعبين والرجوع بعد الانقطاع، وتجهيز البيانات لكل شاشة |
| `src/games/herd.js` | منطق لعبة «عقلية القطيع» |
| `src/normalize.js` | توحيد الكتابة العربية لمقارنة الأجوبة |
| `data/questions.json` | بنك أسئلة «مع القطيع» |
| `data/questions-different.json` | بنك أسئلة «عكس القطيع» |
| `public/` | صفحات المضيف واللاعب (HTML/CSS/JS بدون build) |
| `render.yaml` | إعدادات النشر على Render |

السيرفر هو المرجع لكل شي، ويرسل لكل جهاز صورة كاملة عن حالة اللعبة حسب دوره: اللاعب ما يشوف أجوبة غيره قبل ما تنعتمد النتيجة. البيانات محفوظة في الذاكرة بس، والغرف تنحذف بعد 6 ساعات بدون نشاط.
